# Module 6 — Data Governance, Lineage, and Master Data (2-3 hrs)

**What you'll learn:** How to trace a number back to its source (lineage), how firms keep one clean list of instruments/counterparties (master data management), why this matters for audit and compliance in finance specifically, and how access to sensitive data — like material non-public information (MNPI) — gets restricted to only the people who need it.

**Why it matters:** Regulators and internal audit will eventually ask "where did this number come from?" — you need to know this is a buildable, expected capability, not an afterthought. Separately, because this data touches counterparties and potentially MNPI, "who can see this" is a first-class design question, not something bolted on later — the same governance layer that gives you lineage is usually where access control and need-to-know restrictions get enforced too.
