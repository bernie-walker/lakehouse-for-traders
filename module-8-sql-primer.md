# Module 8 — SQL Primer (4-6 hrs)

**What you'll learn:** Enough SQL to read a query, understand what a JOIN and a WHERE clause do, and follow a technical conversation about "the query is slow because of this join" without needing to write production code yourself.

**Why it matters:** SQL is the one technical skill that pays for itself immediately — it lets you look at the data yourself instead of always waiting on an engineer, and it's the shared language every data person on your team will use to describe problems.

**Resources (pick one path, all free and browser-based — no install needed):**
- [Khan Academy — Intro to SQL](https://www.khanacademy.org/computing/computer-programming/sql) — gentlest pace, no account needed, video + practice mixed
- [SQLBolt — Learn SQL](https://sqlbolt.com/) — 18 short interactive lessons, write real queries in the browser
- [Mode — SQL Tutorial for Data Analysis](https://mode.com/resources/sql-tutorial/introduction-to-sql) — aimed at non-coders moving from Excel to SQL, good real-world framing

**Suggested minimum to cover:** SELECT / WHERE / ORDER BY, GROUP BY + aggregates (COUNT, SUM, AVG), and JOIN (this is the one that unlocks understanding facts+dimensions from Module 4).
